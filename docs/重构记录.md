## 2. 六个阶段做了什么

### 段 1 · 构建链（`4a3ba2f`）

| 改动 | 证据 | 效果 |
|---|---|---|
| 校验函数抽成纯函数 `verify_html/verify_bytes/apply_hashes_to_html` | `verify-csp.py` | 构建可在**写盘前**校验 |
| 构建先校验内存产物、再原子写盘 | `build-html.py:main()` | 哈希过期/模板损坏/危险 sink → 非 0 退出，**两个 HTML 一字节不动**（已实测：改一个空格后 build 失败、`index.html` 的 SHA256 与 mtime 均未变） |
| `updatedAt` 从 git 提交日改为 `data/设置.json` 显式字段 + `--stamp` | `data/设置.json`、`build-html.py` | 本地构建与 CI 构建不再必然产生 diff，`git diff --exit-code` 不再误报 |
| 新增 `\r`/裸 CR/NUL 检查 | `verify-csp.py` | 抓"校验通过但浏览器拒执行"的一类静默白屏 |
| `--apply` 用 `re.subn` 断言替换数量 | `verify-csp.py` | 哈希没替换成功会报错，而不是打印 "updated" |
| 两个 `.bat` 全部加 `errorlevel` 中止 + `%~dp0` + openpyxl 检查；上传脚本先构建再推 | `部署文件.bat`、`上传文件.bat` | 断掉"白屏产物被推上线"的链条 |
| CI 拆成 build / ui 两个 job，matrix 双引擎，加 `timeout-minutes`、`concurrency`，产物不一致时打印可操作提示 | `.github/workflows/verify.yml` | 失败信息可执行，不再只有一行 diff |
| **`index.html` 定为唯一真源**，`实验提醒.html` 降为同步副本 | `verify-csp.py`、`build-html.py` | 消除"改错文件被覆盖"的陷阱（重构过程中真实踩过一次） |

### 段 2 · 样式与首屏（`66a7117`）

- **页头三块化**：`head-row/head-title` → `header.head` = `head-main`（标题+班级）/`head-filters`（两个复选框+计数）/`head-actions`（复制本周、操作）。手机端用 grid + `display:contents` 排成「标题+操作 / 班级 / 筛选」三行。
- **首屏压缩**：`.wrap` 手机端改纵向 flex，用 `order` 把「第 1 周星期一」挪到表格之后；隐藏手机端图例（卡片自带文字标签）与「数据更新至」；时钟压到 12px。347 → 166px，**不动 DOM 结构**。
- **卡片首行裁切修复**：删除 `771` 的 `nowrap + overflow:hidden`，`832` 补 `overflow-wrap:anywhere` 与 `flex:none` 标签。
- **对比度**：`row-past` 文字、三种 tag 底色、卡片边框。
- **焦点可见**：全局 `:focus-visible` 纳入 `input`/`[tabindex]`；6 处 `:focus{outline:none}` 改为 `:focus:not(:focus-visible){outline:none}`，光晕透明度 .15 → .35。
- **悬停**：`filter:brightness()` → `@media (hover:hover)` 背景色，消除 `border-collapse` 下的 1px 暗缝与"今天"被压暗。
- **深色模式**：`:root{color-scheme:light dark}` + 30 行显式覆盖（面/字/边/五种状态色）。
- **平板**：561–940px 两列卡片网格；≤400px 隐藏「班级：」文字标签，班级名不再被压成 73px。
- **打印**：`body/.wrap` 的 `padding:0` 补 `!important`（原来被 940px 块反向覆盖），`break-inside:auto` 允许长备注跨页，备注字号 9.5px → 8.5pt；**`.head-row` 改名后打印规则同步改为 `.head`**（否则页头会印出来）。
- **弹窗**：`max-height: min(92dvh, 640px)`（跟随手机键盘）+ `safe-area` 底部内距。
- 另加：触屏 `:active` 反馈、`prefers-reduced-motion`、复选框 18px、复制/操作按钮 36px 高。

### 段 3 · 结构（`ba5c027`）

- **roving tabindex**：`render()` 生成行时 `tabIndex = -1`，由 `syncRowFocusability()` 只把当前行设 0；`focusin` 同步当前行。25 行 → 1 个 Tab 停靠点，方向键仍是逐条移动，Esc 回表格。

### 段 4 · 功能（`ba5c027`）

- **日历导出 `.ics`**：`操作 → 数据 → 日历（.ics）`，生成标准 `VCALENDAR`：
  - 每班一个文件 `${班级}-实验课.ics`；每条实验一个 `VEVENT`
  - 节次映射 `1-2→08:00-09:40 / 3-4→10:00-11:40 / 5-6→14:00-15:40 / 7-8→16:00-17:40 / 9-10→19:00-20:40`，无法识别时退化为全天事件
  - `VALARM TRIGGER:-PT2H`（提前 2 小时），`VTIMEZONE Asia/Shanghai`，按 RFC 5545 转义并在 75 字节处折行
  - 实测：25 条事件 / 25 个提醒 / 只有 CRLF / 最长行 48 字节 / 页面零报错
- 这是纯静态页面唯一能做到"真正提醒"的路径：导入系统日历后由 OS 负责弹通知，不需要任何后端，也不违反 `connect-src 'none'`。

### 段 5 · 测试

- 新增 `.ics` 端到端断言（下载文件名、`BEGIN:VCALENDAR`、`VTIMEZONE`、事件数等于 `#recentCount` 的总数、75 字节折行）。
- 修掉实测 1/3 概率变红的那条竞态断言（`ui-smoke.mjs:416`）：不再断言状态栏文案，改为等「撤销」按钮出现（状态栏会被并发的跨标签页同步消息覆盖）。
- 更新 roving tabindex 的键盘断言（1 个行级停靠点 + Tab 离开表格）。

### 段 6 · 文档

- README：工作表选择规则（优先 `实验安排`）、`updatedAt`/`--stamp`、构建先校验后写盘、`index.html` 为唯一真源、手机端布局与首屏数字、roving tabindex、深色模式现状、`.ics` 用法、部署路径修正（`D:\MyProgram\HTML\实验提醒` → 真实路径）。

## 3. 刻意没做的（含理由）

| 项 | 理由 |
|---|---|
| 抽 CSS 变量（304 处硬编码） | 逐条替换 `#fff` 这类值必须区分为"面"还是"字"，机械替换在深色下会出错；收益只是可维护性，风险是整页配色崩。深色模式已用显式覆盖实现，真正的 token 化应作为独立提交。 |
| 去掉桌面 46px 空列 | 该列同时是**冲突标识轨道**（`tbody tr.row-conflict td.cell-mark`），去掉会破坏冲突可视化。 |
| `data.json` 懒加载 | gzip 后只省约 10KB，却要放开 `connect-src` 并放弃"单文件可拷走"。 |
| 虚拟滚动/分页 | 2000 条时 `render()` 36ms，当前 65 条离阈值很远。 |
| 冲突色改斜纹 | 现有"同组相邻行连成一条"的边框配色体系与该单元格背景强耦合，斜纹会破坏合并效果，收益小于风险。 |

## 7. 第 3 轮补充（404 页纳入加固 + 校验器单测）

### 7.1 404.html 收进同一套 CSP

原来 404 是唯一没有 CSP 的页面，且带三处与严格 CSP 冲突的写法：

| 问题 | 原写法 | 改法 |
|---|---|---|
| 内联事件属性 | `<button onclick="history.back()">` | 换成 `id="backBtn"` + 现有脚本里 `addEventListener` |
| 内联样式属性 | 5 处 `style="--d:.05s"` 交错动画延迟 | 改成 `.d1`–`.d5` 类，`--d` 写在样式表里 |
| 占位邮箱 | `mailto:hello@example.com` | 改为指向仓库 issues 的链接 |

随后加上与其他页面同一套哈希 CSP，`verify-csp.py --apply` 会一并更新 404 的哈希，校验时会检查：哈希匹配、`default-src 'none'`、`connect-src 'none'`、`base-uri/form-action 'none'`、无外部 `<script src>/<link>/<img>`、无内联事件属性、无危险 DOM sink。

实测（Chromium + WebKit）：**0 条 CSP 违规**、样式表 43 条规则生效、canvas 正常绘制、`--d` 延迟正确、返回按钮可用、控制台无错误。

### 7.2 校验器单测 `tests/test_verifier.py`（16 例）

覆盖"构建先校验后写盘"所依赖的每一项判断：哈希过期、缺模板、危险 sink、CRLF、裸 CR、NUL、BOM、外部脚本、内联事件、`--apply` 修复与幂等性。

顺带修了两个诊断质量问题：`<script src>` 现在报"外部脚本"而不是"内联脚本数量不对"；`<meta ... />` 自闭合写法现在能正确匹配（之前 404 的 meta 匹配不到，导致 `--apply` 直接崩）。

## 8. 第 4 轮补充（首次访问提示 + 诊断信息）

### 8.2 字号阶梯（U9）做了可验证的那一半

原报告说"13 档字号"。实测定位后，真正的问题不是档位多，而是**有一个 UA 默认值在泄漏**：

```css
/* 修前：button/input 没有显式 font-size，浏览器给 13.33px */
button#newClassBtn, input#recentFilter … → 13.3333px
```

给表单控件加 `font-size: inherit` 后，13.3333px 消失（12 档，且都是设计里显式写过的值），布局零变化（320→192、390→166、1440→248，无横向溢出）。

**没有做的**：把 12 档硬压成 6 档。那属于视觉设计走查（每档都对应真实层级），机械合并会改观感；而报告里"最重要的状态语义反而最小"这条实质问题已在第 2 轮修掉（`.tag` 11→12px、`.next-badge` 10.5→11.5px）。

### 8.3 仍未做（有意取舍）
| 项 | 原因 |
|---|---|
| U9 剩余（12 档 → 6 档） | 属于视觉设计改动，牵涉 40+ 条规则和 320px 换行；可验证的异常（UA 默认 13.33px 泄漏、状态标签过小）已修，剩下的合并需要设计走查。 |

## 9. 第 5 轮补充（手机端与桌面端功能对齐）

反馈：手机端没有「数据更新至 2026-11-06」，且「第 1 周星期一」的位置与桌面不一致（之前为腾首屏被排到了表格之后）。

**做法（不牺牲首屏的前提下对齐）**

1. **「数据更新至」移进设置行右侧**（`.data-updated { margin-left: auto }`），桌面和手机同一位置，页头不再拥挤。
2. **设置行回到表格之前**，手机上换成短标签「第1周周一：」（复用已有的 `.label-long/.label-short`），字号与日期控件压到 12px，说明文字在手机隐藏（`title` 保留）。
3. 移动端显式 `order` 重排：head 1 / 首次提示 2 / 操作面板 3 / 设置行 4 / 状态 5 / 时钟 6 / 表格 7 / 诊断 8。
4. **只读模式只隐藏「第 1 周」的编辑控件，「数据更新至」保留**——否则 `?mode=ro` 用户会丢掉"数据是哪天的"这个信息（这是首轮改动带出来的连带 bug，已修）。

**实测**

| 视口 | 首行距顶（再次访问） | 首行距顶（首次访问） | 数据更新至 | 第 1 周 |
|---|---|---|---|---|
| 320 | 247 | — | ✓ | ✓ |
| 390 | **200** | 250 | ✓ | ✓ |
| 1440 | 248（未变） | — | ✓ | ✓ |

手机首屏从 166 → 200px（+34px，仅多出一行压缩后的设置行），仍比重构前的 347px 低 42%；390×844 首屏可见 8 条。

## 10. 第 6 轮补充（404 页认识"你上次看的班"）

只做了一件事，视觉一行没动：404 与主应用同源，读 `localStorage` 里记住的班级，把主按钮从「打开实验课提醒」变成「继续查看 Z2 的实验课」，链接带上 `?class=Z2`。

**安全处理**：班级名先过白名单（`^[\w\u4e00-\u9fa5 .\-]{1,40}$`）再 `encodeURIComponent`，用 `textContent` 写入——即使同源其他页面把这个键写坏，也只能退化成默认按钮，不会变成可执行内容。

**实测（本地 HTTP 服务，五种输入）**

| localStorage 值 | 按钮文案 | href |
|---|---|---|
| 无记录 | 打开实验课提醒 | `/` |
| `Z2` | 继续查看 Z2 的实验课 | `/?class=Z2` |
| `Z1本机` | 继续查看 Z1本机 的实验课 | `/?class=Z1%E6%9C%AC%E6%9C%BA` |
| `<img src=x onerror=alert(1)>` | 打开实验课提醒 | `/`（拒绝） |
| 80 个 `A` | 打开实验课提醒 | `/`（超长拒绝） |

点击穿透：`/404.html` → 点按钮 → `/?class=Z2` → 班级下拉显示 Z2、首次提示不出现。控制台 0 错误，404 仍无 CSP 违规。

## 12. 第 8 轮（周视图从"格子"改成"时间轴"）

周的演示版第一版把节次塞进 5 个固定格子（1-2、3-4…），`第3-8节` 只占一格，看着像"那段时间是空的"。这一轮按用户的四条要求重写：

| 要求 | 做法 | 现场问题 |
|---|---|---|
| 一列一天 | 固定 8 列：44px 节次列 + 7 天 | 之前按重叠数拆子列，1440px 下每格只剩 43px |
| 逐节次行 | 行标签 1、2、3…，`第3-8节` 占 6 行；11 节起自动加行 | 用户数据里出现 `第1-20节`，表格被撑到 20 行 → 上限 14 + `…` 截断标记 |
| 重叠上下→左右 | 先按天数等分，后改成按名称长度加权 | 等分时长名字折两行；加权后 9 字 73px、4 字 32px |
| 整格琥珀 | 冲突时 `background:#ffe6a6` + `inset 0 0 0 2px #b7791f` | 原先只有左色条，不够醒目 |

**同一轮里被实测抓到的三个 bug**：

1. **堆垛用 flex 横向排列**，交叉轴被拉伸 → `第5-7节` 被拉成整格高。改成绝对定位（`left/width` 按权重，`top/height` 按自己的节次）。
2. **`.wg-stack` 容器吃掉点击** → 堆垛覆盖范围内的空格点不动，加实验的入口正好被挡住。改成 `pointer-events: none`，只让子块可点。
3. **「下一次」的蓝色覆盖了今天/明天**：列表和周视图各有一次，两处都改成 `:not(.row-today):not(.row-tomorrow)` / `:not(.st-today):not(.st-tomorrow)`，只保留左侧蓝条；顺带去掉 `今天今天` 这种重复标签。
