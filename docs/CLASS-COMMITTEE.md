# 班委更新本班数据：一页纸

> 适用：Z1 / Z2 / Z5 班委。你只能改**自己班**；改完不会立刻上线，要等管理员合并一次。

## 你会收到三样东西

1. 网站：`https://xiaoyu-oxyz.github.io/`
2. 授权文件：`grant-Z1.json`（换成你班的编号）——解锁编辑用
3. 班级私钥：`Z1.pem`（换成你班的编号）——给文件签名用

> 两个文件都**只给本班用**，不要转发。丢了找管理员重新生成。

## 第一次准备（只做一次）

电脑装 Node.js 18+（<https://nodejs.org> 选 LTS），装完打开命令行输入 `node -v` 能看到版本号即可。

## 每次更新：6 步

### 1. 解锁编辑

1. 浏览器打开网站；
2. 拉到页脚，点 **「解锁编辑」**；
3. 选 `grant-Z1.json`；
4. 标题右边的 **已锁定** 消失 = 成功。

### 2. 改数据

- 确认页面顶部班级是 **Z1**（切到别的班会立刻变回「已锁定」）；
- 点 **操作**，用 **添加实验 / 编辑 / 删除**；
- 改完自动保存，不用点保存。

### 3. 导出

1. **操作 → 导出 → JSON**；
2. 浏览器下载 `Z1-数据-日期.json`；
3. 把它放到一个空文件夹，例如 `D:\Z1更新\`。

### 4. 给文件签名

把 `Z1.pem` 也放进同一个文件夹，然后在该文件夹打开命令行：

```powershell
node <仓库或工具目录>\tools\publish-class.mjs sign `
  --class Z1 `
  --key Z1.pem `
  --in Z1-数据-2026-11-20.json `
  --out Z1.publish.json
```

> 管理员会给你一份 `publish-class.mjs`（或告诉你仓库里 tools 的路径）。
> 成功会输出：`已签名：Z1.publish.json（class=Z1，signer=Z1-publisher）`。

可选自检：

```powershell
node <工具目录>\tools\publish-class.mjs verify --in Z1.publish.json --root <仓库目录>
```

输出 `OK: 班级发布签名有效` 即可。

### 5. 上传到 GitHub Issue

1. 打开仓库 **Issues → New issue**（每次更新新建一个）；
2. 选模板 **「班级数据发布」**；
3. 「班级」下拉选自己的班；
4. 把 `Z1.publish.json` **拖进「签名文件」框**，等附件上传完；
5. 点 **Submit new issue**（不用自己加标签，模板会自动加 `publish`）。

### 6. 等结果

- 约 1–3 分钟，Issue 下会出现评论：
  - 成功：`已创建 PR #xx，等待管理员合并`；
  - 失败：会写原因（签名无效 / 班级未登记 / 附件缺失 / 管理员未配密钥）。
- 管理员合并 PR 后，全班打开网站就能看到新数据。

## 常见失败

| 提示 | 原因 | 怎么办 |
|---|---|---|
| `签名无效` | 用错班的私钥，或文件被改过 | 用本班 `Z1.pem` 重新签名 |
| `名册里没有班级` | 公钥没登记 / 班级写错 | 找管理员 |
| `授权已过期` | 超过 2027-06-30 | 找管理员换钥 |
| `缺少 _publish 签名` | 传的是导出原文件，不是 `.publish.json` | 重新跑第 4 步 |
| Issue 没反应 | 没用「班级数据发布」模板 / 附件没上传完 | 重新用模板提交，等附件上传完再 Submit |
| 管理员说没合并 | 正常，发布会等你点 Merge | 等管理员 |

## 三条铁律

1. **私钥不出本机**：不要发微信、不要放网盘；
2. **只改本班**：切班即锁，别硬来；
3. **上传的是 `.publish.json`**，不是导出的原文件。

## 方式 C：不用装 Node，用网页签名（推荐给班委）

1. 电脑浏览器打开：https://xiaoyu-oxyz.github.io/sign.html
2. 班级选自己的班（如 Z1）；
3. 「班级私钥」选管理员发给你的 `Z1.pem`；
4. 「页面导出的数据」选你从网站上导出的 `Z1-数据-*.json`；
5. 点 **签名并生成文件**；
6. 点绿色 **下载 Z1.publish.json**；
7. 打开 GitHub **Issues → New issue**，选模板 **「班级数据发布」**，选班级，把文件拖进「签名文件」框，点 **Submit new issue**（标签自动加）；
8. 等 1–3 分钟，会自动出现一个 PR；管理员合并后全班可见。

> 私钥只在页面内存里参与签名，不会上传；但仍建议在可信电脑上操作。
> 如果提示"私钥与所选班级不匹配"，说明拿错了班的 pem。
